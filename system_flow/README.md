# แผนภาพและผังขั้นตอนการทำงานทั้งระบบ (System Architecture & Operational Flowchart)
**ระบบห้องปฏิบัติการพยาบาล (Nursing Lab System)**

โฟลเดอร์นี้รวบรวมแผนภาพและผังงานของระบบห้องปฏิบัติการพยาบาล 2 รูปแบบสำคัญ:
