1 สแกนยืนยันตัวตน (Identify)
  • ยิงบาร์โค้ดบน บัตรนิสิต หรือสแกน QR Code หน้าบัตร
  • หรือพิมพ์ค้นหาด่วนด้วย รหัสนิสิต / ชื่อ-นามสกุล
  • กรณีอาจารย์หรือเจ้าหน้าที่ล็อกอินค้างไว้ มีปุ่มคลิกเลือกเป็นชื่อตนเองได้ทันที
  • แสดงรูปโปรไฟล์, สาขาวิชา, และสิทธิ์การใช้งานบนหน้าจอ
2 เลือกรายวิชา / วัตถุประสงค์
  • เลือก รายวิชา ที่กำลังฝึก (เช่น พย.1102)
  • ระบบจะดึงยอดค่าใช้จ่ายไปคำนวณใน Cost Analytics ของวิชานั้นทันที
  • หากไม่ใช่คาบเรียนปกติ สามารถเลือก:
    • ซ้อมทักษะอิสระ (Self-Practice)
    • เตรียมการสอน / สอบ OSCE
3 สแกนพัสดุต่อเนื่อง (Continuous Scan)
  • รองรับเครื่องยิง Barcode USB หรือกล้อง iPad/Tablet มีเสียง "Beep!" ตอบรับ
  • แยกแยะประเภทอัตโนมัติ:
    • Box Code ตัดกล่องนั้นโดยเฉพาะ
    • Pack Code ตัดซองสเตอร์ไรด์รายชิ้น
    • Item Code บวกจำนวนในตะกร้า +1
    • Asset Code เพิ่มรายการ "ยืมครุภัณฑ์"
4 ตรวจสอบตะกร้า (Cart Review)
  • แสดงรายการสิ่งของทั้งหมดพร้อมรูปภาพ และหน่วยนับ
  • มีปุ่ม + / - ปรับจำนวน หรือกดถังขยะลบรายการ
  • แสดงผลคำนวณ มูลค่าต้นทุนรวม (Total Cost) ของการเบิกครั้งนี้
  • แจ้งเตือนทันทีหากมีรายการใดที่สต็อกในคลังไม่เพียงพอ
5 ตัดสต็อกทันที (Instant Checkout)
  • ตัดยอดคงคลังทันทีแบบ FEFO (ล็อตหมดอายุก่อนตัดก่อน)
  • เปลี่ยนสถานะในระบบเป็น DISPENSED อัตโนมัติ
  • สร้างประวัติใน RequisitionRequest สถานะเสร็จสิ้น เพื่อให้ข้อมูลรายงานผู้บริหารตรงกันทั้งระบบ
  • ส่งข้อมูลตัดจ่ายไปยังตารางบัญชีต้นทุนต่อวิชา Real-time
6 ออกสลิปบันทึก (E-Receipt)
  • หน้าจอแสดงใบเสร็จดิจิทัล (E-Receipt) พร้อม QR ตรวจสอบ
  • ปุ่มพิมพ์สลิปกระดาษความร้อน 80mm Thermal Printer สำหรับเหน็บไว้ที่โต๊ะหัตถการ
  • บันทึก Audit Trail ระบุวัน-เวลา และเคาน์เตอร์ที่ทำรายการ
  • เคลียร์หน้าจอพร้อมให้บริการผู้เบิกคนถัดไปทันที
