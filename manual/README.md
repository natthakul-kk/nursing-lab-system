# คู่มือการใช้งานระบบห้องปฏิบัติการพยาบาล (Nursing Lab System User Manual)

โฟลเดอร์นี้รวบรวมคู่มือการใช้งานระบบห้องปฏิบัติการพยาบาล ฉบับสมบูรณ์ ทุกรูปแบบไฟล์:

### จุดเด่นของคู่มือฉบับสมบูรณ์ (Version ล่าสุด):
1. **เนื้อหาและขั้นตอนละเอียดครบทุกระบบ**: ครอบคลุมตั้งแต่การเข้าสู่ระบบ, การจัดการรายวิชา, การจัดชุดอุปกรณ์, การเบิก-จ่าย-คืน, การตรวจนับสต็อก และสถิติผู้บริหาร
2. **มี Flowchart แสดงขั้นตอนการทำงาน**: มีแผนภาพสรุปกระบวนการทำงานในแต่ละโมดูลอย่างชัดเจน
3. **ใช้ชื่อจำลอง (Demo/Anonymized Data)**: ใช้ชื่อจำลอง เช่น นายสมเกียรติ พยาบาลสถาพร, นางสาวศิริพร สุขเกษม แทนข้อมูลผู้ใช้จริง
4. **ไม่มีโค้ดโปรแกรมติดมา**: ลบคำสั่งหรือโค้ดเทคนิคที่ไม่เกี่ยวข้อง (เช่น `/practice`, `/kits`, URLs, enums) ออกทั้งหมด
5. **จัดหน้าสวยงามด้วยฟอนต์ TH Sarabun New 16pt**: อ่านง่าย สบายตา เหมาะสำหรับพิมพ์หรือส่งต่อ
